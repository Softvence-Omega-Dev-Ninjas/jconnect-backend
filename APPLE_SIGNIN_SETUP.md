# 🍎 Apple Sign-In Setup Guide for JConnect

## Problem

You're getting this error when trying to sign in with Apple:

```
Firebase: Error (auth/operation-not-allowed)
```

## Solution

### Step 1: Enable Apple Sign-In in Firebase Console

1. **Go to Firebase Console**
    - Visit: https://console.firebase.google.com/
    - Sign in with your Google account

2. **Select Your Project**
    - Click on project: **jconnect-b6f89**

3. **Navigate to Authentication**
    - Click **Authentication** in the left sidebar
    - Click **Sign-in method** tab at the top

4. **Enable Apple Sign-In**
    - Scroll down to find **Apple** in the list of providers
    - Click on **Apple**
    - Toggle the **Enable** switch to ON
    - Click **Save**

### Step 2: (Optional) Configure Apple Sign-In for Production

For **production** use, you'll need to configure additional settings:

1. **Apple Developer Account Required**
    - You need an Apple Developer account ($99/year)
    - Visit: https://developer.apple.com/

2. **Create a Services ID**
    - Go to Apple Developer Console
    - Navigate to **Certificates, Identifiers & Profiles**
    - Click **Identifiers** → **+** (plus button)
    - Select **Services IDs** → Continue
    - Fill in:
        - Description: JConnect Web Sign-In
        - Identifier: com.jconnect.signin (or similar)
    - Click **Continue** → **Register**

3. **Configure the Services ID**
    - Click on your newly created Services ID
    - Check **Sign In with Apple**
    - Click **Configure**
    - Add domains and return URLs:
        - Domains: `jconnect-b6f89.firebaseapp.com`
        - Return URLs: `https://jconnect-b6f89.firebaseapp.com/__/auth/handler`
    - Click **Save** → **Continue** → **Done**

4. **Create a Key**
    - In Apple Developer Console
    - Go to **Keys** → **+** (plus button)
    - Name: JConnect Sign In Key
    - Check **Sign In with Apple**
    - Click **Configure** → Select your primary App ID
    - Click **Save** → **Continue** → **Register**
    - **Download the key file** (you can only download once!)
    - Note your **Key ID** and **Team ID**

5. **Add to Firebase**
    - Back in Firebase Console → Authentication → Sign-in method → Apple
    - Enter:
        - Services ID
        - Apple Team ID
        - Key ID
        - Upload the private key file (.p8)
    - Click **Save**

### Step 3: Test Your Implementation

1. **Open the test file**
    - Open `firebase-auth-test-fixed.html` in your browser

2. **Click "Sign in with Apple"**
    - A popup should appear with Apple's sign-in page
    - Sign in with your Apple ID
    - Grant permissions

3. **Verify Token**
    - After successful sign-in, you'll see:
        - User info displayed
        - Token sent to backend
        - Backend response shown

## Common Issues & Solutions

### Issue 1: Popup showing token

**This is normal behavior!** The Apple Sign-In popup is showing you the authorization flow. After you confirm, the token is:

1. Generated by Firebase
2. Sent to your backend at `http://localhost:5050/auth/firebase-login`
3. Displayed in the user info section

### Issue 2: `auth/popup-closed-by-user`

**Cause:** User closed the popup before completing sign-in  
**Solution:** Try again and complete the sign-in flow

### Issue 3: `auth/popup-blocked`

**Cause:** Browser is blocking popups  
**Solution:** Allow popups for this site in your browser settings

### Issue 4: Backend connection failed

**Cause:** Backend server is not running  
**Solution:** Make sure your NestJS backend is running:

```bash
cd c:/Users/Shamim Rana/workspace/jconnect-backend
pnpm run start:dev
```

## Testing Flow Explanation

Here's what happens when you successfully sign in:

1. **User clicks "Sign in with Apple"** button
2. **Popup opens** with Apple's sign-in page
3. **User enters** Apple ID and password
4. **Apple authenticates** and returns authorization
5. **Firebase receives** the authorization and creates a user
6. **Firebase generates** an ID token (JWT)
7. **Frontend sends** the ID token to your backend
8. **Backend verifies** the token with Firebase
9. **Backend creates/updates** user in database
10. **Backend returns** user data and JWT token
11. **Frontend displays** user information
